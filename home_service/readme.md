# 🏨 Home Services — Service Stats Page

A responsive hotel landing/stats page built with HTML and CSS, featuring a split-layout design with a hero image section and a stats section.

---

## 📁 Project Structure

```
home_services/
├── index.html
├── style.css
└── README.md
```

---

## 🚀 Getting Started

1. Clone or download the project files.
2. Open `index.html` in any modern web browser — no build step or dependencies required.

> ⚠️ An active internet connection is needed to load Google Fonts and the logo/background images hosted externally.

---

## 🖼️ Preview

### Mobile (< 992px)
- Stacked layout: hero image on top, stats section below.
- Hero section displays the hotel logo, name, and tagline over a full-width background image.

### Desktop (≥ 992px)
- Side-by-side layout: hero image on the left, stats content on the right.
- Larger heading and expanded spacing for a premium feel.

---

## 📐 Layout & Design

| Section | Description |
|---|---|
| **Top Section** | Background cover image with logo, hotel name, and tagline |
| **Bottom Section** | Hotel description paragraph + stats cards grid |
| **Stats Cards** | 4 key metrics: Countries, Hotels, Rooms, Employees |
