# Student Startup Landing Page

A responsive startup landing page built using **HTML, CSS, and JavaScript**.
This project includes a responsive navigation bar with a hamburger menu for mobile devices and a modern hero section.

## 🚀 Features

* Responsive Navbar
* Mobile Hamburger Menu
* Modern Hero Section
* Flexbox Layout
* Responsive Typography
* Clean UI Design
* Beginner-Friendly Project Structure

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome

## 📱 Responsive Design

The website adapts to different screen sizes:

* Desktop View
* Tablet View
* Mobile View

## 📂 Project Structure

```bash
project-folder/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🎯 Functionalities

### Navigation Bar

* Logo Section
* Navigation Links
* Signup Button
* Hamburger Menu for Mobile Devices

### Hero Section

* Fullscreen Background Image
* Startup-Themed Heading
* Responsive Text Scaling

## ⚡ JavaScript Features

* Toggle mobile navigation menu
* Responsive menu interaction using `classList.toggle()`
